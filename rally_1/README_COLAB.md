# Ejecución en Google Colab

Abrir el notebook `analisis_series_tiempo_colab.ipynb` desde GitHub o subirlo directamente a Google Colab. Seleccionar **Entorno de ejecución > Cambiar tipo de entorno de ejecución > Python 3** y ejecutar todas las celdas en orden.

El notebook descarga las series desde Yahoo Finance al momento de la ejecución y utiliza un corte fijo hasta el 24 de septiembre de 2026 para que los resultados sean comparables con el Rally 1.
