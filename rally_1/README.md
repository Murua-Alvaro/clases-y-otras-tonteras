# Rally financiero 1 — análisis de series de tiempo

Este apartado contiene el análisis cuantitativo utilizado para estudiar la dinámica del tipo de cambio USD/MXN y su relación con variables financieras internacionales.

## Contenido

- Descarga de datos diarios de mercado.
- Construcción de rendimientos logarítmicos.
- Estadística descriptiva y correlaciones.
- Prueba ADF de estacionariedad.
- ACF y PACF.
- Modelo ARIMA para el USD/MXN.
- Modelo SARIMAX con S&P 500, VIX y Treasury a 10 años como variables exógenas.
- Regresión con errores HAC para medir sensibilidad contemporánea.
- Validación fuera de muestra con MAE y RMSE.
- Pronóstico y comparación contra un benchmark ingenuo.

El notebook está preparado para ejecutarse en Google Colab con Python 3.
